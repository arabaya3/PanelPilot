## Blocker

**B1, environment, not a code defect as far as I can tell.**

- Opening 4 new tabs on /design at the same moment in the multi-tab context left every tab on "Internal Server Error".
- `panelpilot-web-1` then answered 500 to every page, including `/` and `/api/v1/health` through the proxy, for more than 10 minutes. Its status became "unhealthy".
- The container log repeats `Watchpack Error … ENOMEM: not enough memory, scandir '/repo/apps/web/src/app/design'`.
- The Docker VM had 168 MB free and 2.3 GB of swap in use. Several supabase stacks were running, plus a second `panelpilot-api` container (`adoring_wing`) that I did not start.
- I did not restart it, as the brief says. Steps 10–13 need a re-run once the web container is restarted, ideally with more Docker memory.
- Likely reproduction: on a memory-tight Docker Desktop, open 5 tabs of http://127.0.0.1:3000/design at once on the dev server.

## Observations

- **O1. No name field on the design screen's sign-up.** The "Create an account" form has only Email and Password. A user who signs up there always approves as "a team member" and has no way to set a name. Only /join (by invite) or the API takes a full name.
- **O2. The export language comes from the drawing, not the page.** Switching the page to ar or he and exporting gives a byte-identical calculations PDF (same md5), in English with "a team member". This is by design (`drawing_text.APPROVER_FALLBACK` is said in the drawing's language). With the revision's Drawing language set to ar or he, the body is localized: "اعتمدها أحد أعضاء الفريق للمراجعة" and "אושר לסקירה על ידי חבר צוות".
- **O3. The stamp line is not localized.** In an ar or he drawing, the stamp/identity line at the top and bottom stays English: "REVIEW APPROVED — STUDY… approved by a team member on …". The English fallback therefore sits inside a localized document (18, 19).
- **O4. One status message does not follow the language switch.** After a save, "Saved as revision 1." stays in English when the page is switched to ar or he (13-trial-*-ar/he).
- **O5. Credentials in the run output.** A's disposable password appeared once in the run output, because the Playwright tool echoes its script. It was never written to any file outside `.test-accounts.local`. It is a localhost account. Treat it as exposed or delete the account.
